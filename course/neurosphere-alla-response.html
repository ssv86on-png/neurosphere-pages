💬 Промпт-инжиниринг — глубокое изучение

Отдельный, детально проработанный блок программы. Научитесь писать промпты, которые дают предсказуемый результат на любой модели:

🎯

Базовый

Структура промпта, роль, контекст. Chain-of-Thought, Few-shot. Системный промпт. Температура, top-p.

⚡

Продвинутый

Мультишаговые цепочки, Self-Consistency, Tree-of-Thoughts. Роутинг между моделями. Промпт-фабрики.

🤖

Боевой

Промпты для агентов (tool use). Защита от инъекций. A/B тестирование. Промпты для функций и код-генерации.

💻 Программирование нейросетей — 10 уровней

Полный трек: от первого скрипта на Python до собственной архитектуры, продакшена и развёртывания.

🔰 Уровень 1 — Python для ИИ

Основы Python. NumPy, Pandas. Jupyter Notebooks. Первые скрипты.

📊 Уровень 2 — Обработка данных

Загрузка, очистка, визуализация. Matplotlib, Seaborn. Датасеты для обучения.

🧮 Уровень 3 — Математика нейросетей

Матрицы, градиенты, обратное распространение. Графы вычислений.

🏗 Уровень 4 — Нейросети с нуля

Нейрон, слой, функция активации на чистом Python + NumPy. Перцептрон.

⚙️ Уровень 5 — PyTorch

Тензоры, автоград, модули. Сборка и обучение. Dataset, оптимизаторы.

🖼 Уровень 6 — Свёрточные сети (CNN)

LeNet, ResNet. Классификация, Transfer Learning. GPU.

🔤 Уровень 7 — NLP / Transformers

Токенизация, Attention. HuggingFace. Fine-tuning LLM.

🎨 Уровень 8 — Генеративные модели

Stable Diffusion, LoRA, ControlNet. Генерация контента.

🔗 Уровень 9 — RAG + Multi-Agent

LangChain, Chroma, FAISS. Агенты-планировщики, супервизоры.

🚀 Уровень 10 — Продакшн

Docker, FastAPI, ONNX. Квантизация (GGUF). vLLM. VPS/Vercel.

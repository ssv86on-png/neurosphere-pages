💬 Промпт-инжиниринг — глубокое изучение

Отдельный блок программы. Вы научитесь писать промпты, которые дают предсказуемый результат на любой модели:

🎯

Базовый уровень

Структура промпта, роль, контекст, формат ответа. Chain-of-Thought, Few-shot. Работа с системным промптом.

⚡

Продвинутый

Мультишаговые цепочки, Self-Consistency, Tree-of-Thoughts. Роутинг между моделями. Контроль температуры, top-p, frequency penalty.

🤖

В бою

Промпты для агентов. Функциональные промпты (tool use). Защита от инъекций. A/B тестирование промптов. Промпт-фабрики.

💻 Программирование нейросетей — 10 уровней

Полный трек: от первого скрипта на Python до собственной нейросетевой архитектуры.

🔰 Уровень 1 — Python для ИИ

Основы Python: переменные, функции, классы. NumPy, Pandas для работы с данными. Jupyter Notebooks.

📊 Уровень 2 — Работа с данными

Загрузка, очистка, визуализация данных. Matplotlib, Seaborn. Подготовка датасетов для обучения.

🧮 Уровень 3 — Линейная алгебра для нейросетей

Матрицы, векторы, градиенты. Производные и обратное распространение ошибки. Визуализация графов вычислений.

🏗 Уровень 4 — Основы нейросетей с нуля

Написание нейрона, слоя, функции активации на чистом Python и NumPy. Перцептрон, сигмоида, ReLU.

⚙️ Уровень 5 — PyTorch / TensorFlow

Тензоры, автоград, модули. Сборка и обучение полносвязных сетей. Dataset, DataLoader, оптимизаторы.

🖼 Уровень 6 — Свёрточные сети (CNN)

Архитектуры: LeNet, ResNet, EfficientNet. Классификация изображений, Transfer Learning, Fine-tuning. Работа с GPU.

🔤 Уровень 7 — NLP и Transformers

Токенизация, эмбеддинги, Attention. HuggingFace Transformers: BERT, GPT, T5. Fine-tuning LLM под свою задачу.

🎨 Уровень 8 — Генеративные модели

Diffusion models: Stable Diffusion, LoRA, ControlNet. GANs. Генерация изображений, видео, музыки. Коммерческое применение.

🔗 Уровень 9 — RAG и Multi-Agent системы

LangChain, LlamaIndex. Retrieval-Augmented Generation. Chroma, FAISS. Мульти-агентные архитектуры: планировщики, супервизоры, специализированные агенты.

🚀 Уровень 10 — Продакшн и развёртывание

Docker, FastAPI, ONNX. Квантизация (GGUF, GPTQ). vLLM, llama.cpp. Мониторинг, A/B тесты, CI/CD для ML. Развёртывание на VPS, Vercel, Cloudflare.
